Storages

A Storage is a Zenoh router plugin that persists publications and serves them to future get() requests — with full location transparency.

Enabling a Storage

Add to your router configuration:

Architecture

The storage plugin intercepts publications flowing through the router and persists them. When a get() arrives, the plugin serves the stored values — all transparently through the same router.

The application doesn't know (or care) whether the reply comes from:

  • A live publisher
  • A storage on an edge router
  • A storage in the cloud

Storage Backends

BackendUse case
memoryEphemeral, zero-config, built-in
rocksdbDurable local persistence
influxdbTime-series data
s3Object storage (AWS S3, MinIO)

Backends are loaded as plugins. See the eclipse-zenoh/zenoh-backend-* repositories for the full list.
